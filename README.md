# 🌱 FarmCV Sell
### AI-Based Crop Disease Detection & Smart Marketplace

## 📌 Overview
FarmCV Sell is a Python-based AI and Computer Vision project designed to help farmers detect crop diseases early and sell healthy produce directly to buyers. The system combines deep learning with a digital marketplace to improve productivity and farmer income.

---

## 🚀 Features
- 🌿 Crop Disease Detection using Deep Learning (EfficientNetV2)
- 📷 Image-based analysis of crop leaves
- ⚡ Real-time disease prediction with high accuracy
- 💊 Treatment suggestions and preventive measures
- 🛒 Digital Marketplace for selling healthy crops
- 📱 Mobile-friendly and easy-to-use interface

---

## 🧠 Technologies Used
- Python
- TensorFlow / Keras / PyTorch
- OpenCV
- NumPy, Pandas, Scikit-learn
- Flask / FastAPI (Backend)
- React / Streamlit (Frontend)
- MySQL / MongoDB (Database)

---

## ❗ Problem Statement
Farmers often struggle to detect crop diseases early due to lack of expert knowledge, leading to crop loss. Additionally, they depend on middlemen to sell produce, reducing their profits.

---

## 💡 Solution
FarmCV Sell uses AI and Computer Vision to:
- Detect diseases from crop images
- Provide instant diagnosis and solutions
- Enable direct selling through a digital marketplace

---

## ⚙️ How It Works
1. User uploads crop leaf image
2. Image is preprocessed and passed to the AI model
3. EfficientNetV2 model predicts disease
4. System shows:
   - Disease name
   - Confidence score
   - Suggested treatment
5. If crop is healthy → farmer can list it for sale

---

## 📊 Model Details
- Model: EfficientNetV2 (CNN-based)
- Techniques:
  - Image preprocessing
  - Data augmentation
  - Transfer learning
- Evaluation Metrics:
  - Accuracy
  - Precision
  - Recall
  - F1-score
